
# 🚀 files-splice-uploader-大文件分片上传

**大文件多文件分片上传解决方案 前端 vue3 服务端 node + koa + mysql**

Node.js 版本要求：`^20.0.0`

## ✨ 核心功能
- ⚡ **多文件上传**：支持同时上传多个文件
- 🧩 **进度展示**：文件上传状态展示
- 🗺 **断点续传**：支持大文件上传中断后继续上传
- 📐 **分片上传**：大文件上传时将文件分片上传
- 🛡 **同文件极速上传**：支持同文件多线程上传
- 👨‍🌾 **服务端**：Node.js + Koa + MySQL
